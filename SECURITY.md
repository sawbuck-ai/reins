# Reporting a security problem

Found a security problem in the Sawbuck plugins for Claude Code? Tell us in private first. Please do not open a public issue for it.

## How to report

Open the **Security** tab of this repository and press **Report a vulnerability**. Or use this link:
https://github.com/sawbuck-ai/reins/security/advisories/new

You need a GitHub account. Only you and the maintainers of this repository can read what you send.

## What to send

- The version you ran, your system and your Node version.
- What you did, what happened, and what you expected.
- A small repo or the exact commands that show it, if you can.

## What happens next

We read every report and answer in that same private thread. A fix ships as a new version. The newest version is
the one that gets fixes.

The plugins run the `sawbuck` package from npm. A problem in that package can be sent the same way at
https://github.com/sawbuck-ai/sawbuck/security/advisories/new

## Everything else

Bugs and questions that are not a security problem: https://github.com/sawbuck-ai/reins/issues
